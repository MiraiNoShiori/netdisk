## 已实现

- S3 流式上传、Seek/Range 下载、按序分片合并、异常 multipart 中止、混合后端读取、双向迁移和五分钟直链。
- NFSv3 TCP 网关，单用户导出，来源 CIDR 校验；通过同一业务层读写用户文件。
- P2P 分享类型、限时信令房间、权限校验、浏览器 WebRTC 发送/接收与写入确认。
- 持久化登录会话、登出、资料修改、改密码、账号删除；登录/注册限流。
- 上传后端持久化、过期清理、失败删除重试、完整 hash/大小校验、无损失败重传、收尾事务和跨进程会话锁。
- 增量迁移、OpenAPI（37 个操作）、CI、容器构建、中文运行说明。

## 验证边界

- NFS 验收使用真实 TCP 协议客户端，未在宿主机安装 nfs-common 做内核 mount 实测；README 提供 GNU/Linux 挂载命令。
- P2P 使用同一主机的两个独立浏览器进程实测兼容下载路径；未声称跨公网 NAT、两台物理设备或大文件 File System Access 保存路径已实测。实现目标是局域网内演示。
- MinIO 官方旧公开镜像拉取失败，验收采用固定官方源码版本 `RELEASE.2025-10-15T17-29-55Z` 编译的 Windows/Linux 实例。
- CI 配置已加入；没有推送到 GitHub，因而没有远端 Actions 运行记录。Compose 配置已校验；整套容器镜像构建未作为本机验收依据。
- 本次没有重跑 500MB RSS 性能实验，不沿用它作为新后端的性能证明。
- 回收站、分页搜索、配额、分享密码、邮箱验证与 refresh token 未实现；NFS 的属性/锁/覆盖 rename 边界见 README。

开发与验收使用独立代码副本、测试库和对象存储。项目的 `.env`、`data/` 与本地压缩包不进入仓库，也不作为测试素材。
